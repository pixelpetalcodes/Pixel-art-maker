# 🎨 Pixel Art Maker

A browser-based pixel art editor built with **HTML, CSS, and JavaScript**. Create your own pixel-art drawings using a customizable grid, colors, and drawing tools.

## ✨ Features

* 🖌️ Draw and color individual pixels
* 🎨 Choose from multiple colors
* 🌈 Select a custom color
* 🧹 Erase pixels
* 🔲 Choose different grid sizes
* 🖼️ Download your artwork as a PNG
* 💻 Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/pixelpetalcodes/Pixel-art-maker.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start creating your pixel art! 🎨
